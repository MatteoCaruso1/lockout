## App Review information
**Sign-in required:** No.

**Notes for the reviewer:**
> Lockout is a self-control app for the iPhone's owner. It uses Family Controls with individual authorization (AuthorizationCenter .individual), ManagedSettings to shield apps and web domains during a lock, and DeviceActivity so each lock ends on time even if the app is closed. It makes no network requests and collects no data.
>
> To test without being locked for long: finish the 1-minute setup (allow Screen Time access; screen 2 is optional), then tap "Try a 2-minute lock" on screen 3 or on the home screen. After the 10-second countdown every app and website is shielded for 2 minutes and then released automatically. Phone and emergency calls are never blocked. A lock cannot be ended early by design; that is the product. Locks are capped at 12 hours (24 hours with extensions).
>
> Strict mode (optional, Home → Make it stricter) only displays a 4-digit code and asks the user to type it into Settings → Screen Time themselves; the app never changes system settings on its own.
